# Disaster AI Project

An AI-based disaster management system that helps in predicting and analyzing disasters using machine learning.

---

## 🚀 Features
- Disaster prediction using ML models
- Data analysis using datasets
- Model training and evaluation
- Modular agent-based architecture

---

## 🛠 Tech Stack
- Python
- Machine Learning (Scikit-learn)
- Pandas, NumPy

---

## 📂 Project Structure
- agents/ → AI agents logic  
- data/ → datasets  
- models/ → trained models  
- app.py → main application  
- train_model.py → model training  

---

## ▶️ How to Run

1. Install dependencies:
   pip install -r requriments.txt

2. Run the application:
   streamlit run app.py
3.Requirements:
streamlit
spacy
openai
pandas

4.Example:
Input:"There is heavy flood in my area"
Output:Flood
